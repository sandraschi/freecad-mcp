## Session Context (FreeCAD MCP)

You have access to 46+ FreeCAD CAD/CAM/CAE tools via MCP.

**Before starting work:**
1. Check FreeCAD availability: freecad_status()
2. Check slicer status: slicer_status()

**Capabilities:**
- Core CAD: STEP/STL conversion, model info, shape creation
- BIM: walls, slabs, columns, windows, doors, roofs, IFC import/export
- CFD: OpenFOAM case building, solver, parametric studies, PINN sampling
- FEM: CalculiX structural analysis, materials, constraints, meshing
- FluidX3D: GPU CFD setup, compile, run, results
- Slicing: PrusaSlicer G-code generation
- Marketplace: Printables/Thingiverse/GrabCAD search and download
- REST API at 127.0.0.1:10944
- Webapp at 127.0.0.1:10945
